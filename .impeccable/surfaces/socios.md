# Socios — Dashboard operativo

## Scope

Ruta `/socios`, móvil y escritorio, para socios y administradores autorizados.

## Direction contract

**THESIS:** Exception Queue First. La pantalla existe para encontrar y resolver la siguiente excepción; rechaza el dashboard de tarjetas equivalentes.

**OWN-WORLD:** Precision Modern con Paper, Navy e Ink como estructura; Cobalt para acción; Sky para contexto y Amber dosificado para logística o vencimiento.

**STORY:** el socio entiende qué exige decisión ahora, actúa, confirma qué riesgo desapareció y solo después consulta estado o análisis.

**FIRST VIEWPORT:** sidebar compacta; encabezado utilitario; cola priorizada dominante; una banda de máximo cuatro KPIs compactos. La primera acción permanece visible sin desplazamiento.

**FORM:** dirección fijada por el usuario como “Precision Modern” y “Exception Queue First — recomendada”; `seed: none (pinned)`.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
